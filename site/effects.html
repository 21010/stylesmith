Dynamic Effects

Hardware-accelerated. Zero-idle-cost. Fully responsive to your OS reduced-motion preferences.

Matrix Rain

A highly optimized HTML5 Canvas overlay that drops fading matrix characters when you type. Costing 0 bytes of memory when idle.

CRT Flicker

Mimics a dying CRT monitor by injecting micro-translations into the editor viewport via CSS hardware acceleration.

Caret Animation

When the text cursor moves, it glides to its new place and leaves a short trail behind it, making it easier to track your jumps.

Typing Sparks

Each key you type throws small neon pixel sparks up from the cursor that arc, fall, and fade out.

Glitch on Save

The editor glitches for a moment with a quick red and cyan split every time you save a file.

Boot Sequence

A retro boot log types itself out over the window during startup and fades away.
