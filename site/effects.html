Native Settings

These options use VS Code's documented settings API. They take effect in the editor without injecting styles or scripts into the workbench.

Smooth cursor

Uses editor.cursorSmoothCaretAnimation: on and editor.cursorBlinking: smooth, VS Code's built-in cursor animation.

Current line

Uses editor.renderLineHighlight: all to highlight the active line.

Bracket guides

Uses editor.guides.bracketPairs: active to show the guide around the active bracket pair.

Compact layout

Uses window.density.layout: compact in VS Code versions that provide this setting.

Block editor cursor

Uses editor.cursorStyle: block for a terminal-style block cursor in the editor. Off by default.

Block terminal cursor

Uses the native terminal cursor style and blinking settings.

Dim unfocused editors

Uses accessibility.dimUnfocused.enabled to dim the editors and terminals you aren’t working in, so the focused one stands out. Off by default.

Undo highlight

Uses VS Code’s editor decorations to tint the lines an undo changed for a moment, so you can see what came back. Turn it on with stylesmith.undoHighlight. Off by default.

Stylesmith leaves the workbench files untouched

Enable and Disable manage these settings through VS Code. Disable restores the settings Stylesmith saved.
