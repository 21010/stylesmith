Custom Typography

Stylesmith bundles four popular Nerd Fonts. They load directly inside VS Code as web fonts, meaning you don't have to install anything on your operating system.

JetBrainsMono

The default developer staple. High legibility, excellent ligatures, and a sleek modern aesthetic.

function init() {
  console.log("JetBrains");
}

BlexMono

Based on IBM Plex Mono. A highly engineered, precise font that excels in high-contrast environments.

  console.log("BlexMono");
}

ShureTechMono

A condensed, futuristic technical font. Perfect for compact cyberpunk layouts and dense log analysis.

function init() {
  console.log("ShureTech");

DepartureMono

A monospaced pixel font with a lo-fi tech vibe. Delivers the ultimate retro CRT or terminal aesthetic.

How to apply a font

Note: When you apply a Stylesmith preset, the optimal font for that aesthetic is automatically loaded for you. However, you are always free to override it or use your own custom local font.

  1. Open the menu: Click the Stylesmith paint-can icon in your VS Code status bar, or open the Command Palette (Cmd/Ctrl + Shift + P) and run Stylesmith: Show Menu.
  2. Select Typography: Click the Font option to open the typography picker.
  3. Pick a bundled font, or use your own: Choose one of the bundled Nerd Fonts from the list. If you prefer to use a custom font installed on your OS, simply select "Use my own font" to disable Stylesmith's web font injection. Stylesmith will reload the editor window to apply your change.
