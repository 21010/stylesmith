How to install a font

Download the .zip above and unpack it. Each family has several files; the ones ending in NerdFontMono are the ones Stylesmith uses.

  1. Windows: select the NerdFontMono files, right-click and choose Install (no administrator rights needed).
  2. macOS: open the files and click Install Font in Font Book.
  3. Linux: copy the files to ~/.local/share/fonts and run fc-cache -f.
  4. Then restart VS Code, so it sees the new font.

How to apply a font

Stylesmith presets choose themes, icons and native settings. They do not change your font. Install a Nerd Font family on your system before selecting it here.

  1. Open the menu: Click the Stylesmith paint-can icon in your VS Code status bar, or open the Command Palette (Cmd/Ctrl + Shift + P) and run Stylesmith: Show Menu.
  2. Select a font: Click the Font option to choose a system-installed family.
  3. Choose a family: Stylesmith sets the editor and terminal font names through VS Code. It does not install font files, inject web fonts, or reload the window.
