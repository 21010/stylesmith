01 // Presets

A preset sets up a complete look in one step: a color theme, the pixel icons, a Nerd Font and a set of effects. Afterwards you can still change anything on its own.

There's also a High Contrast preset, with nothing that moves.

02 // What's in the kit

Your own CSS and JS

Add your own files to change anything in VS Code's interface. They stay in place until you turn them off, and a VS Code update doesn't make you start over: Stylesmith offers to apply them again.

Effects

A gliding caret, a neon current line, glowing code blocks and selections, CRT scanlines, typing sparks, a boot sequence and a glitch on save. The loud ones are off until you turn them on, and none of them do any work while you're idle.

Problem Lens

Errors and warnings right on their line: a soft tint, a pixel icon in the gutter, the message at the end of the line, and the problem in the status bar.

Six color themes

Dark, light and high contrast. Every theme is checked against the WCAG contrast levels and simulated for color blindness, so the colors that carry meaning stay apart.

Nerd Fonts

JetBrainsMono, BlexMono, ShureTechMono and DepartureMono, bundled and set for the editor and terminal. Your own fonts stay as fallbacks.

Classic layout

Prefer square corners and tabs that look like tabs? One switch brings back the classic look of VS Code, and puts your settings back when you turn it off.

03 // Security comes first

Tools that change VS Code's look have to change VS Code's own files. Stylesmith does it without turning off what keeps VS Code secure:

  • VS Code's security policy stays on. Only the exact scripts Stylesmith adds are allowed to run, each by its fingerprint.
  • A project can't change what runs. Settings are read from your user settings only, never from a workspace you open.
  • Your files, on your terms. No http://, https:// only if you allow it, a size limit, and optional fingerprints that refuse a file that changed.
  • Always reversible. Disable and uninstall put VS Code's file back byte for byte.
  • Checked on every change. About 1,800 tests, browser and end-to-end tests in a real VS Code, CodeQL and OpenSSF Scorecard.

Found a problem? Please report it privately, as described in the security policy.

04 // Install

Get Stylesmith from the VS Code Marketplace: search for "Stylesmith" in the Extensions view, or run: 

code --install-extension 21010.stylesmith

Get it on the Marketplace

Then open the Command Palette and run Stylesmith: Enable, or click the paint-can button in the status bar and pick a preset. The README explains every setting.

Each version is also on GitHub as a .vsix file with a signed build provenance, so you can check that it was built from the public source.
