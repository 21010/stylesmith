05 // Tested for Readability

Minimum Contrast

Every theme is tested for contrast: at least 7:1 for editor text and 4.5:1 for every syntax color, also on the current line.

◐

Glare Cap

Outside the high-contrast themes, there's no pure white on pure black, and editor text stays at or below 16:1, a design choice meant to reduce glare.

Color-Vision Deficiencies

Error and warning colors, git gutter colors, and terminal red and green are tested to stay apart under simulated protanopia, deuteranopia and tritanopia.

06 // Secure by Design

Uses documented extension APIs

Themes and icon themes are manifest contributions. Problem Lens uses editor decorations and diagnostics APIs. Settings are changed through VS Code.

Leaves installation files alone

Stylesmith does not read or write workbench.html, product.json, or other files in the VS Code installation.

Does not run workspace code

Stylesmith does not load project files or settings to select and execute code, and it declares support for untrusted workspaces.

Workspace Immunity

Stylesmith does not load code or configuration from the opened workspace. Other extensions and code remain subject to VS Code's own trust controls.

07 // Quickstart

  2. Enable: Open the Command Palette (Ctrl+Shift+P or Cmd+Shift+P) and run Stylesmith: Enable.
