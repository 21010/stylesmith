Oh My Posh

Extend the retro aesthetic outside the editor. We provide a matching Oh My Posh terminal prompt theme that dynamically follows your active Stylesmith color palette.

How it works

Oh My Posh is a custom prompt engine for any shell that has the ability to adjust the string shown in the prompt. Stylesmith ships with an official Oh My Posh theme file (`stylesmith.omp.json`) that uses terminal environment variables to automatically sync with your currently active VS Code theme colors.

Installation

  1. Install Oh My Posh: Follow the official Oh My Posh documentation for your OS.
  2. Get the Stylesmith theme: Download the official configuration file. 
    curl -O https://raw.githubusercontent.com/21010/stylesmith/main/extras/oh-my-posh/stylesmith.omp.json
  3. Configure your Shell: Set Oh My Posh to use the downloaded theme. For PowerShell, add this to your `$PROFILE`: 
    oh-my-posh init pwsh --config ~/stylesmith.omp.json | Invoke-Expression
