TERMINAL INTEGRATION

Vim & Neovim

Edit in the terminal without leaving your theme behind. The Stylesmith Vim color scheme follows your active VS Code palette automatically.

How it works

The included stylesmith.vim color scheme uses your terminal’s 16 named ANSI colors instead of fixed 24-bit hex codes. Because every Stylesmith theme defines a contrast-checked terminal palette, Vim and Neovim take on your active preset’s colors in VS Code’s integrated terminal and update right away when you switch themes.

Checked for contrast

Every highlight group in stylesmith.vim uses only the terminal ANSI colors that Stylesmith’s automated tests check for at least 4.5:1 contrast on the terminal background (7:1 in high-contrast themes), with ctermbg=NONE so the terminal’s own background shows through.

Covers standard Vim syntax groups, line numbers, search, diffs, spelling, and Neovim diagnostic highlights.

The color scheme in every theme

Because stylesmith.vim uses your terminal’s color names, one color scheme adapts to all 24 Stylesmith themes. Here is a code sample in each theme’s real terminal colors: comments, keywords, functions, numbers, strings, and the active line number.

Installation

  1. 1. Download the color scheme

    Save stylesmith.vim to your Vim or Neovim colors folder. For Vim: 

    curl -fLo ~/.vim/colors/stylesmith.vim --create-dirs https://raw.githubusercontent.com/21010/stylesmith/main/extras/vim/colors/stylesmith.vim

    Or for Neovim:

    curl -fLo ~/.config/nvim/colors/stylesmith.vim --create-dirs https://raw.githubusercontent.com/21010/stylesmith/main/extras/vim/colors/stylesmith.vim

  2. 2. Enable the color scheme

    You can also copy stylesmith.vim offline from inside VS Code via Stylesmith: Show Menu → Terminal & editor add-ons…. The scheme turns off 24-bit termguicolors automatically so Vim and Neovim use the terminal’s ANSI palette; load stylesmith in your ~/.vimrc or ~/.config/nvim/init.vim: 

    set notermguicolors
syntax on
colorscheme stylesmith

    Or in Neovim’s Lua configuration (~/.config/nvim/init.lua): 

    vim.opt.termguicolors = false
vim.cmd.colorscheme("stylesmith")
