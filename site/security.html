Security Model

Modifying your editor's core files sounds terrifying. It should be. Here is exactly how Stylesmith patches VS Code without blowing a hole in your machine's defenses.

Content Security Policy (CSP)

The Risk

Disabling or blindly relaxing VS Code's Content Security Policy allows any malicious extension or untrusted workspace to execute untrusted scripts inside your editor context.

The Fix

Stylesmith injects strict CSP headers. It only permits its own static assets (like bundled fonts) and local CSS. It never uses unsafe-eval or opens broad script execution vectors.

Why It Matters

You get a custom UI without opening a backdoor into your local development environment.

The Checksum Lock

The Risk

VS Code monitors its own installation files. If malware modifies your editor, it displays a "corrupt installation" warning. Other UI-patching tools completely disable this warning, blinding you to actual threats.

The Fix

Stylesmith recalculates the cryptographic checksum of the core HTML file after making its own modifications, and updates the editor's lockfile to match the new hash.

Why It Matters

VS Code's integrity check stays fully active. If a virus or rogue tool alters your files later, the checksum will break and you will instantly be warned.

Failsafe Architecture

The Risk

VS Code updates frequently. Hard-coded UI patches can easily crash the editor, leaving you locked out of your workspace after a Tuesday morning update.

The Fix

Stylesmith's patches are structural and non-destructive. If an upstream VS Code update breaks the CSS hooks, the modifications fail without breaking the editor.

Why It Matters

Zero downtime. Your editor will never refuse to boot because of a theme.

Workspace Immunity

The Risk

Extensions that globally modify UI styles often leak CSS into embedded webviews (like Markdown previews or third-party extension pages), breaking their layout.

The Fix

Stylesmith strictly scopes all visual modifications to the main workbench container, isolating it from the rest of the application.

Why It Matters

Your code, extension menus, and markdown previews look exactly as their authors intended, with no visual artifacts.

CRITICAL ADVISORY: The "Corrupt Installation" Warning

If you ever see a "Your VS Code installation appears to be corrupt" message while Stylesmith is active, DO NOT IGNORE IT. Never attempt to permanently disable this warning using third-party extensions.

Because Stylesmith updates the editor's cryptographic lockfile for its own modifications, seeing this warning means something else has modified your editor's core files without your knowledge. This usually indicates a broken VS Code update, a rogue extension leaking code, or worst case, a malicious script attempting to hijack your editor environment. Always investigate the root cause.
